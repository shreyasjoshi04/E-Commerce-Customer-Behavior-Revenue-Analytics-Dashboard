# Data Dictionary

> **Note:** all data in this repository is **synthetic**, generated by `scripts/01_generate_raw_data.py`
> (seed = 42) to simulate an Indian online retailer. It contains no real customer information.

## `data/raw/ecommerce_transactions_raw.csv` (12,010 rows, 13 columns)
Intentionally messy: 210 duplicate rows, mixed date formats (`YYYY-MM-DD` and `DD/MM/YYYY`), inconsistent
casing/whitespace, missing values (age, city, payment method, discount) and 25 invalid quantities (≤ 0).

| Column | Description |
|---|---|
| order_id | Unique order identifier (ORD000001…) |
| customer_id | Customer identifier (CUST00001…) |
| order_date | Order date (mixed formats in raw) |
| gender | Male / Female |
| age | Customer age (18–65) |
| city | Customer city (10 Indian cities) |
| product_category | 6 categories: Electronics, Fashion, Home & Kitchen, Beauty & Personal Care, Books & Stationery, Sports & Fitness |
| product_name | Product purchased |
| quantity | Units ordered |
| unit_price | Price per unit in INR |
| discount_pct | Discount applied (0–30 %) |
| payment_method | UPI, Credit Card, Debit Card, Cash on Delivery, Net Banking, Wallet |
| order_status | Delivered / Cancelled / Returned |

## `data/processed/ecommerce_transactions_clean.csv` (11,775 rows, 25 columns)
All raw columns (standardised) plus:

| Column | Description |
|---|---|
| gross_amount | quantity × unit_price |
| discount_amount | gross_amount × discount_pct / 100 |
| revenue | Net order value = gross_amount − discount_amount |
| is_realised | 1 if order_status = Delivered |
| realised_revenue | revenue for Delivered orders, else 0 |
| order_year, order_month, order_month_name, year_month, order_quarter, day_of_week | Date features |
| age_group | 18-24, 25-34, 35-44, 45-54, 55+ |

## `data/processed/rfm_segments.csv` (one row per buying customer)
| Column | Description |
|---|---|
| last_order | Date of last Delivered order |
| recency | Days from last order to snapshot date (max order date + 1) |
| frequency | Number of Delivered orders |
| monetary | Total realised revenue (INR) |
| R, F, M | Quintile scores 1–5 (5 = best) |
| rfm_score | Concatenated score, e.g. "555" |
| segment | Champions, Loyal Customers, New / Promising, Needs Attention, At Risk, Hibernating, Lost |
| is_churned | 1 if recency > 90 days |
| gender, age, age_group, city | Customer attributes for slicers |
